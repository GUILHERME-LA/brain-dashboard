# Brain Dashboard 🧠

**Dashboard inteligente para organização de estudos e produtividade** — centralize seus materiais, acompanhe seu progresso e otimize seu aprendizado.

[![Vercel](https://img.shields.io/badge/🔗_Acessar_App-000000?style=for-the-badge&logo=vercel&logoColor=white)](https://brain-dashboard-kappa.vercel.app)

---

## ✨ Funcionalidades

- 📚 **Gerenciamento de matérias e conteúdos**
- ⏱️ **Pomodoro integrado** para sessões de estudo
- 📊 **Gráficos de desempenho e progresso**
- 📝 **Anotações e resumos** organizados por disciplina
- 🎯 **Metas diárias e semanais** com tracking
- 🔔 **Lembretes inteligentes** para revisão

## 🚀 Como Executar Localmente

```bash
# Clone o repositório
git clone https://github.com/GUILHERME-LA/brain-dashboard.git

# Acesse a pasta
cd brain-dashboard

# Instale as dependências
npm install

# Configure as variáveis de ambiente
cp .env.example .env.local

# Inicie o servidor de desenvolvimento
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000) no navegador.
